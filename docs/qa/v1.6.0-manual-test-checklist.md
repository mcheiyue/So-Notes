## 测试概述

v1.6.0 主要增强快速捕获（Quick Capture）功能，包括：
- 目标看板标签显示优化（C16/C26）
- 捕获失败输入保留（C24）
- 批量创建高亮与选区契约（C25）
- 批量撤销/重做支持（C27）
- C28 范围纪律强制执行

## 测试前置条件

1. 已安装 SoNotes v1.6.0 应用
2. 应用已启动，主界面正常显示
3. 至少创建一个看板（例如："工作看板"）
4. 确保快速捕获功能可用（快捷键或菜单）

## 已知问题

1. **C29 捕获后定位功能**：v1.6.0未交付，此功能将在后续版本中实现
2. **ESLint规则**：`react-hooks/set-state-in-effect`规则在快速捕获组件中可能触发，但这是预期行为，不影响功能

## 测试建议

1. **自动化测试**：运行`npm run check:smoke`验证冒烟测试基线
2. **单元测试**：运行`npx vitest run src/components/QuickCaptureOverlay.test.tsx`验证UI测试
3. **Store测试**：运行`npx vitest run src/store/useStore.test.tst -t "store 历史:" -t "store 契约:"`验证数据层测试
4. **类型检查**：运行`npm run typecheck`验证TypeScript类型
5. **Lint检查**：运行`npm run lint`验证代码规范
