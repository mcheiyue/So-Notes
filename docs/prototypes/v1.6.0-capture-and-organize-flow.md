## 目标看板

- 入口：全局快捷键唤起 Quick Capture 浮层。
- 浮层标题区定稿：**快速捕获 · {label}**，其中 `label = resolveQuickCaptureBoardLabel(看板名)`；`null` / 空 / 仅空白 → **当前看板**；非空名称则 `label` 为看板名本身（**不再**叠一层「当前看板 ·」前缀）。
- 看板名过长：单行截断（`truncate`），悬停可看全名（可选）。
- 不引入「页面 / 工作区 / 项目」等新称呼。

```
┌─────────────────────────────────────┐
│  快速捕获 · 工作                     │
│  ┌─────────────────────────────┐   │
│  │ 输入灵感…                     │   │
│  └─────────────────────────────┘   │
│              [取消]  [创建]          │
└─────────────────────────────────────┘
（空名示例：快速捕获 · 当前看板）
```

---

## 捕获成功

1. 在当前视口统一落点创建文本便签（与现网 `getViewportSpawnOrigin` 一致）。
2. 关闭浮层并清空输入。
3. 新便签短时高亮（脉冲或描边），便于扫视定位。
4. **可选**：程序定位视口到新便签——仅当 Viewport Action gate 已落地且当前无 active drag / edge-push / sticky drag；否则只高亮不强制平移。
5. 领域创建进入 Undo；视口平移与选区变化不进入 Undo。

---

## 捕获失败

1. submit 路径抛错时（实施验收以 spy/mock 注入；现网 batch **非 async、仅本地 store**）：浮层保持打开，**输入内容保留**，展示固定可读错误（实施稿钉死：`role="alert"` + `创建失败，输入已保留`）。
2. 用户可改文案后重试，或取消关闭（取消是否丢弃草稿在实现 commit 写死；默认取消清空、失败保留）。
3. 失败路径不写入半截领域便签。

---

## 不做

- 不做标签系统、模板系统。
- 不做多端合并、双向类能力、WebDAV 同步或云同步产品形态。
- 不做协作、SQLite / libSQL、数据库迁移。
- 不做自动拉取、自动下载、自动恢复。
- 不做图片查看大改、搜索重构（Spotlight 大改）。
- 本原型仅描述捕获主路径，不扩展为全站信息架构重设计。
