## 8. 收尾自检（无法自动证明 / 最可能返工）

1. **`pub(crate)` 过宽**：测外置后为编译把大量 API 改 `pub` → 审 diff，能 `pub(crate)` 不 `pub`。  
2. **filter 假绿**：`webdav` 子串命中 0 或只跑到空模块 → 必须抓 `running 0 tests`。  
3. **逻辑顺手改**：拆分 commit 夹带 SSRF/超时/重试变更 → C-SPLIT-5 靠审，无字节级行为 diff 工具。  
4. **循环 use**：启发式 §5.3 非完备（`use super::*` 盲区）→ 依赖 code review + 编译。  
5. **ignore 集成测**：本机无 WebDAV 不跑；不宣称「真机备份已验」。  
6. **Cargo.lock**：若仅 path 变更通常不改锁；禁止顺手升依赖。  
7. **PowerShell**：`$LASTEXITCODE` 在管道后可能被冲掉 → §5 用 `Out-String` 后先查 exit，或 `; if (-not $?)`。
