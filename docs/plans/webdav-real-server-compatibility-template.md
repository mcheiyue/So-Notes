# WebDAV 真实服务端兼容记录模板

---

## 1. 使用说明

本模板用于记录 SoNotes 与真实 WebDAV 服务端的兼容性检查结果。每份记录对应一个服务端版本和部署环境，便于后续将观测到的协议现象转化为自动化 fixture。

**记录原则：**

- 只记录可脱敏的协议现象，不记录真实账号、密码、token 或私人 URL。
- 不声称"测试通过"或"完全兼容"，只记录观测到的行为。
- 可脱敏的响应样例应脱敏后附上，便于 fixture 还原。
- 每份记录应独立可读，不依赖其他记录。

## 4. 注意事项

1. **脱敏要求：** 所有 URL、用户名、token 必须脱敏，使用 `example.com`、`username`、`your-token` 等占位符。
2. **观测记录：** 只记录实际观测到的行为，不推测未测试的场景。
3. **fixture 转化：** 当观测结果被转化为 fixture 时，应在"测试覆盖状态"中注明 fixture 路径。
4. **版本关联：** 每份记录应注明 SoNotes 版本和记录日期，便于后续版本对比。
5. **独立性：** 每份记录应独立可读，不依赖其他记录的上下文。

```

```

## 7. 与 v1.5.3 的关系

本模板是 v1.5.3 计划的 Commit 11 产物，用于补充真实服务端兼容记录能力。模板本身不作为版本验收硬门槛，只作为后续用户反馈的沉淀工具。

**v1.5.3 验收相关：**

- 模板可用于记录真实服务端行为。
- 记录结果可转化为 fixture，用于自动化测试。
- 模板不改变 v1.5.3 的 mock 优先策略。
