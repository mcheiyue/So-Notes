## 0. 背景与输入

v1.5.2–v1.6.0 代码审查综合评分 **8.0/10**（8.5 体验 + 7.0 结构）。审查发现：

- **P0 安全（3 项）**：WebDAV SSRF 防护三缺陷（DNS Rebinding / IP 范围不全 / fail-open）
- **P1 可靠性（4 项）**：敏感词不一致 / catch 未 sanitize / 三层锁重叠 / webdav.rs 巨体
- **P2 架构债（4 项）**：setViewMode 语义分叉 / useStore 双轨 / coordinator 无看门狗 / cliff 生命周期

**行数基线（实测，非约数口号）**：`webdav.rs` 物理 ~8448、非空 ~7406（含大块 `#[cfg(test)]`）；`BoardDock.tsx` 非空 ~3221 / 物理 ~3438（禁止只写「~3.4k」）。复杂度债登记与关闭状态以 `docs/guidelines/overengineering-audit-reference.md` 为真源；关闭项时回写状态字。

v1.6.0 快速捕获契约已通过（8.5/10，无关键问题）。本规划延续「安全债 > 体验债 > 结构美学」的优先序，将审查报告 **11 项** + CodeGraph 结构发现 + **发布体积债**（建议.md）+ **UX 体验债 45 项**（UX 审查报告）分配到 **10 个版本**（v1.6.1–v1.6.9 主做安全/架构/体积/数据可信，v1.7.0 体验主线 + 强制性能/a11y 包），每个版本保持「**一主主题 + 附带关闭审查项**、可验证、Non-goals 写死」节奏。

## 1. 总体原则

### 1.1 继承（不改变）

- **v1.6.0 已承诺的 Non-goals 仍成立**：不做全用户同步、不做多窗口、不做数据库替换。
- **本地优先 / 捕获优先 / 可撤销优先 / 备份优先于同步**（路线图四项）。
- **先故事后骨架**：不从「设计图」开始，从「最小可用故事」开始。
- **一版一主主题**：每个版本有一个完整可感知主主题（用户体验或工程可靠性）；允许 **附带关闭审查项**（小补丁），但不得反客为主。

### 1.2 新增

- **安全债优先**：CODE P0 安全（SSRF）必须在体验债之前封闭。
- **审查报告为输入源**：CODE 以 `D:\BACK\So-Notes-v1.5.2-v1.6.0-代码质量审查报告.md` 为准；UX 以 `D:\BACK\SoNotes-UX审查报告.md` 为准；**编号与简述不得改写原文语义**。
- **CodeGraph 为结构参考**：影响半径以 `codegraph impact` / `codegraph affected` 结果为准。
- **可验证 > 美观**：每个版本必须有可执行测试或手动烟测步骤；不为「整洁」单独开版本。
- **体积债**：错依赖导致的可感知膨胀（如 keyring 4）优先于依赖二次抠体积；不单独为「美学瘦身」开版。
- **覆盖 = 唯一版本 + 状态字 + 验收**（见 §0.1）；禁止无主 backlog。
- **复杂度债登记真源**：以 `docs/guidelines/overengineering-audit-reference.md` 登记；关闭项时回写状态字。
- **UX 债前移**：数据可信与危险操作（UX P0-05/09/10/11）及焦点陷阱（P0-04）在 **v1.6.9 强制关闭**，不得仅手测；性能/a11y 大项在 **v1.7.0 强制包**关闭，不依赖「是否选中候选 E/F」。
- **安全/SSRF 不因 UX 推迟**：UX 补丁不得插入 v1.6.1。

## 2. 明确非目标（v1.6.1–v1.7.0 全期不做）

| 非目标 | 理由 |
| --- | --- |
| 全用户同步 / 协作 | 复杂度爆发；本地优先路线图未到 |
| 多窗口 / 多实例 | 需先收敛状态模型 |
| 应用内自动安装更新（L2） | 本规划仅做 L0（发现）+ L1（检查）；L2 下一规划窗口 |
| 强制更新 / 差分更新 | 便携 exe 分发无需；复杂度远超收益 |
| 非 GitHub 更新源 | 仅支持 GitHub Releases；多源增加 SSRF 攻击面 |
| 数据库替换（SQLite / IndexedDB） | 备份栈优先级更高 |
| 标签系统大改 | 全期不做；若 v1.7.0 锁定候选 A，仅允许「最小可用标签」并在该版实施稿写死边界 |
| Spotlight 大改 | 体验主线未到 |
| 全局 Undo/Redo 栈重构 | 只在版本内修补缺失，不重写栈；候选 B 仅补齐缺失，不重写栈 |
| 全局 Viewport Action 框架 | v1.6.0 已砍，本规划仍不做 |
| 备份恢复后端 / WebDAV 同步协议 | 全期不做；若 v1.7.0 锁定候选 D，仅允许恢复 **UI 层** |
| 合并三层备份锁为单一锁源 | R3 有意降级（见 v1.6.8）；仅文档化 + 超时，不合并锁 |
| CSS-in-JS / 样式迁移 | 非当前债项 |
| 发布产物二次瘦身（reqwest/rustls/image/zip/profile） | 收益远小于修 keyring；全期不做；仅 v1.6.2 修 keyring 错 crate + v1.6.9 建体积门禁 |
| 非 Windows 平台 keyring store 完整矩阵 | 当前以 Windows 主路径验证；其它平台仅保证编译/文档，不扩 scope |
| UX 审查 P2 作为 v1.6.x **主主题** | 不进 v1.6.x 主主题；**必须**进 v1.7.0 品质关闭清单（可有意延后但写去向） |
| UX 45 项拆成独立版本序列 | 破坏一主主题；仅允许「主主题 + 附带关闭项」与 §16.4 台账 |
| 全局 a11y 认证 / WCAG 全站合规 | v1.7.0 a11y **强制包**仅为最小基线，非认证项目 |
| 以「六选一候选」使 UX 可不做 | 废止；v1.7.0 体验主线仅 A/B/C/D 四选一，**性能包 + a11y 包强制并行** |
| 合并 confirmStore 与 quitConfirmStore | **保持分离**（quit 含备份状态）；全期不做合并 |

## 4. v1.6.1：WebDAV SSRF 安全收口

> **主题**：封闭 WebDAV SSRF 防护三缺陷，使远程备份不再可被本地攻击者利用  
> **范围**：仅 WebDAV 客户端安全边界；不改业务逻辑、不拆模块  
> **预计规模**：小–中（仅 `webdav.rs` SSRF 路径 + 测试 + 配置接口）

### 4.0 关闭的审查项

| ID | 来源 | 简述 | 完成后状态字 |
| --- | --- | --- | --- |
| CODE S1 | 代码质量 | DNS Rebinding / TOCTOU | **已收窄**（连接时 IP pin + reqwest 主机名证书校验；**不做**证书钉 IP / 独立 SAN 二次构造） |
| CODE S2 | 代码质量 | 禁用 IP 范围不全 | **已修复** |
| CODE S3 | 代码质量 | DNS 失败放行（fail-open） | **已修复**（fail-closed；trust = DNS 失败时重试一次，**不跳过** IP 黑名单） |

本版 **无 UX 关闭项**（安全优先，禁止插入 UX）。

### 4.1 入选问题（审查报告 P0 ×3）

| 编号 | 审查问题 | 本版修复 |
