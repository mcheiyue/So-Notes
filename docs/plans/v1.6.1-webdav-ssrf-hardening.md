### 文案变更

仅新增信任主机控件文案：「信任此主机（DNS 失败时重试；IP 黑名单仍生效）」。

**注意**：此文案明确"DNS 重试"语义——trust 仅在 DNS 失败时重试一次，重试仍失败则 reject；不跳过 S2 IP 黑名单、不跳过 redirect 校验。用户自家 NAS 若为内网 IP（192.168.x.x）或解析到内网 IP，仍会被拒绝。

### 通用约束：对外错误信息脱敏

> **脱敏规则（写死）**：对外错误文案（返回给前端 / UI 的 `String`）应统一为笼统表述，例如「不能指向本机或内网」「主机校验失败」「DNS 解析失败」。**禁止**把解析得到的具体 IP、完整 DNS 错误细节、内部 socket 列表直接暴露给前端。
>
> - 解析 IP / DNS 细节 / 重试次数 → 仅进 `tracing::warn!` / `tracing::debug!`
> - 前端可见文案 → 笼统、可本地化、不辅助攻击者探测内网拓扑
> - 单测可断言笼统文案子串（如「禁止」「DNS」），**不得**要求断言具体 IP 出现在对外 `Err` 中（内部 tracing 可另测）
>
> **统一错误出口（P1-7，写死）**：所有对外 `Err` 必须经过以下函数输出。该函数内部保留 `detail` 进 `tracing::warn!`，返回笼统文案。**禁止**绕过此函数直接 `format!("...{ip}...")` 构造对外错误。
>
> ```rust
> /// 脱敏对外错误：内部 detail 进 tracing，返回笼统文案
> pub(crate) fn sanitize_webdav_error(detail: &str) -> String {
>     tracing::warn!("WebDAV 错误（内部）: {}", detail);
>     // 返回笼统文案，不暴露具体 IP / DNS 细节
>     // 使用 keyword 前缀匹配而非 contains，避免子串误命中
>     let lower = detail.to_ascii_lowercase();
>     if lower.starts_with("dns") || lower.starts_with("解析") || lower.contains("dns 解析") {
>         "DNS 解析失败".to_string()
>     } else if lower.contains("黑名单") || lower.contains("本机") || lower.contains("内网") || lower.starts_with("ip 字面量") {
>         "主机校验失败：不能指向本机或内网".to_string()
>     } else if lower.starts_with("重定向") || lower.contains("redirect") {
>         "重定向校验失败".to_string()
>     } else if lower.starts_with("reqwest") || lower.contains("连接") || lower.contains("超时") {
>         "WebDAV 连接失败".to_string()
>     } else {
>         "WebDAV 操作失败".to_string()
>     }
> }
> ```
>
> **调用点清单**（实施时逐一替换 `Err("...".into())` 为 `Err(sanitize_webdav_error("..."))`）：
> - `resolve_and_check`：IP 字面量黑名单、DNS 失败、解析后 IP 黑名单
> - `validate_webdav_redirect_url`：跨 host、trailing-dot、pin key 不一致、redirect 后 IP 黑名单、端口不匹配
> - `resolve_and_pin`：透传 `resolve_and_check` 的 Err
> - `build_webdav_http_client`：reqwest Client 构建失败、连接超时等底层错误
> - **禁止**：任何 `Err(format!("..."))` 绕过此函数直接对外暴露细节
>
> **双轨边界 + 唯一对外出口（P0-10 写死）**：
> - **SSRF 路径**（`resolve_and_check` / `validate_webdav_redirect_url` / pin / redirect / 主机校验 / `build_webdav_http_client` 构建失败）：**唯一**出口 `sanitize_webdav_error` → 固定公开串。
> - **非 SSRF 传输层**（现网 `webdav_error_message(&WebDavOperationError)` ~L2928）：继续服务 HTTP/IO 分类文案；**禁止**在 SSRF 路径直接 `map_err(|e| e.to_string())` 或 `format!("{e}")` 把 reqwest/DNS 细节拼进 IPC。
> - **禁止双轨**：同一 SSRF 失败既走 sanitize 又走另一条含 IP/DNS 的字符串路径。
> - **create/client 工厂不暴露 reqwest 到 crate 公 API（P0-10）**：
>   - 现网 `build_webdav_http_client(...) -> Result<reqwest::Client, reqwest::Error>`（~L435）改造后签名为 `Result<reqwest::Client, String>`（Err 已经 sanitize），**Client 类型可留在 crate 内**；**禁止** `pub use reqwest::...` 或把 `reqwest::Error` 作为 `pub` 命令返回类型。
>   - 五入口对外仍返回业务 Result / `webdav_error_message`；SSRF 拒绝在进入操作前以 `String` sanitize 文案失败。
> - **错误码/串迁移表**：
>
> | 场景 | 旧（或内部 detail） | 新公开串（sanitize 后） |
> |------|---------------------|------------------------|
> | DNS fail | 含 resolve 细节 / fail-open 无文案 | `DNS 解析失败` |
> | 私网/黑名单 IP | 可能含具体 IP | `主机校验失败：不能指向本机或内网` |
> | redirect 非法 | 可能含 `HTTPS`/host 明文 | `重定向校验失败` |
> | client build / 连接 | `reqwest::Error` Display | `WebDAV 连接失败` 或经 `webdav_error_message` 的既有分类（非 SSRF） |
>
> - **§6 断言**：`error_sanitization_no_ip_leak` 等对 Err **`not` 含** `192.168.` / 具体 socket 文本。
> - **静态门**：
>   ```bash
>   # shell: 任意
>   rg -n "format!.*\\{(ip|addr|socket)" src-tauri/src/webdav.rs
>   # SSRF 邻域 0 命中对外路径
>   rg -n "^pub use reqwest::|^pub \(.*reqwest::Error" src-tauri/src/webdav.rs
>   # 期望 0 命中（禁止公 API 再导出 reqwest）
>   node -e "
>   const s=require('fs').readFileSync('src-tauri/src/webdav.rs','utf8');
>   if(/pub\\s+use\\s+reqwest::/.test(s)){console.error('FAIL P0-10: pub use reqwest');process.exit(1);}
>   if(/fn\\s+build_webdav_http_client[^{]*reqwest::Error/.test(s)){
>     console.error('FAIL P0-10: build_webdav_http_client still returns reqwest::Error');process.exit(1);
>   }
>   console.log('OK P0-10: no pub reqwest re-export; client Err is String');
>   "
>   ```
>
> #### 断言文本迁移表（P0-4，sanitize 后 `redirect_guard_*` 必须改断言；禁止实施者猜测）
>
> | 测试名 | 现状断言（改造前） | sanitize 后**公开**子串（必须改用） | 内部 detail（仅 tracing，测试不得要求） |
> |--------|-------------------|--------------------------------------|----------------------------------------|
> | `redirect_guard_rejects_http_target` | `err.contains("HTTPS")` | **`err.contains("重定向校验失败")`**（或 `starts_with("重定向")` 映射后的公开串） | `"重定向目标必须使用 HTTPS"` |
> | `redirect_guard_rejects_https_private_target` | `err.contains("本机") \|\| err.contains("内网")` | **`err.contains("主机校验失败")` 或 `err.contains("不能指向本机或内网")`** | 含具体 IP 的 detail |
> | `redirect_guard_rejects_https_localhost_target` | `err.contains("本机") \|\| err.contains("内网")` | **同上：公开笼统串** | 含 localhost 的 detail |
> | `redirect_guard_accepts_public_https_target` | `unwrap()` 无 Err | 保持 Ok；无公开串断言 | — |

### §5.1 C-W1 S2 IP 扩展（`is_disallowed_webdav_ip`）

**目标**：IPv4 新增 CGNAT/TEST-NET/240+/multicast/broadcast/0.0.0.0/8/198.18.0.0/15/192.0.0.0/24；IPv6 新增 multicast/文档地址/6to4/NAT64 嵌入/deprecated-site-local/NAT64 非 WKP/100::/64（Discard-Only）/2001:2::/48（Benchmarking）/Teredo 2001:0::/32。

**实现**：
```rust
fn is_disallowed_webdav_ip(ip: IpAddr) -> bool {
    match ip {
        IpAddr::V4(v4) => {
            v4.is_loopback()
                || v4.is_private()                    // 10/8, 172.16/12, 192.168/16
                || v4.is_link_local()                 // 169.254/16
                || v4.is_unspecified()                // 0.0.0.0
                || is_unspecified_net(v4)             // 0.0.0.0/8（不仅 0.0.0.0）
                || v4.is_multicast()                  // 224/4
                || v4.is_broadcast()                  // 255.255.255.255
                || is_cgnat(v4)                       // 100.64/10
                || is_test_net(v4)                    // 192.0.2/24, 198.51.100/24, 203.0.113/24
                || is_reserved_240(v4)                // 240/4
                || is_benchmark(v4)                   // 198.18.0.0/15（RFC 2544）
                || is_ietf_shared(v4)                 // 192.0.0.0/24（RFC 6890）
        }
        IpAddr::V6(v6) => {
            // IPv4-mapped → 递归 V4
            if let Some(v4) = v6.to_ipv4_mapped() {
                return is_disallowed_webdav_ip(IpAddr::V4(v4));
            }
            // 6to4 嵌入 IPv4 → 解嵌后递归
            if let Some(v4) = extract_6to4(v6) {
                return is_disallowed_webdav_ip(IpAddr::V4(v4));
            }
            // NAT64 WKP 嵌入 IPv4 → 解嵌后递归
            if let Some(v4) = extract_nat64(v6) {
                return is_disallowed_webdav_ip(IpAddr::V4(v4));
            }
            v6.is_loopback()
                || v6.is_unspecified()
                || v6.is_unique_local()               // fc00::/7（使用 std 方法）
                || v6.is_unicast_link_local()         // fe80::/10
                || v6.is_multicast()                  // ff00::/8
                || is_documentation_ipv6(v6)          // 2001:db8::/32, 3fff::/20
                || is_deprecated_site_local(v6)       // fec0::/10（RFC 3849 已废弃，但安全起见仍拒绝）
                || is_nat64_non_wkp(v6)               // 64:ff9b:1::/48（RFC 6052 NAT64 非 WKP）
                || is_discard_only_ipv6(v6)           // 100::/64（RFC 6666 Discard-Only）
                || is_benchmarking_ipv6(v6)           // 2001:2::/48（RFC 5180 Benchmarking）
                || is_teredo(v6)                      // 2001:0::/32（RFC 4380 Teredo）
        }
    }
}

fn is_unspecified_net(ip: Ipv4Addr) -> bool {
    ip.octets()[0] == 0  // 0.0.0.0/8（不仅 0.0.0.0）
}

fn is_cgnat(ip: Ipv4Addr) -> bool {
    ip.octets()[0] == 100 && (ip.octets()[1] >= 64 && ip.octets()[1] <= 127)
}

fn is_test_net(ip: Ipv4Addr) -> bool {
    matches!(ip.octets(), [192, 0, 2, _] | [198, 51, 100, _] | [203, 0, 113, _])
}

fn is_reserved_240(ip: Ipv4Addr) -> bool {
    ip.octets()[0] >= 240
}

fn is_benchmark(ip: Ipv4Addr) -> bool {
    ip.octets()[0] == 198 && (ip.octets()[1] >= 18 && ip.octets()[1] <= 19)  // 198.18.0.0/15
}

/// 192.0.0.0/24（RFC 6890 IETF Protocol Assignments / Shared Address Space）
/// 该段用于 DS-Lite 等运营商内部，非用户可达公网
fn is_ietf_shared(ip: Ipv4Addr) -> bool {
    ip.octets()[0] == 192 && ip.octets()[1] == 0 && ip.octets()[2] == 0
}

fn is_documentation_ipv6(ip: Ipv6Addr) -> bool {
    // 2001:db8::/32 (RFC 3849)
    (ip.segments()[0] == 0x2001 && ip.segments()[1] == 0x0db8)
    // 3fff::/20 (RFC 9637) — 首段 = 0x3fff，第二段高 4 位 = 0
    || (ip.segments()[0] == 0x3fff && (ip.segments()[1] & 0xf000) == 0)
}

/// fec0::/10（已废弃的 site-local，RFC 3849）
/// fec0::/10 = fec0:: to febf::... — 前 10 位 = 1111111011
fn is_deprecated_site_local(ip: Ipv6Addr) -> bool {
    (ip.segments()[0] & 0xffc0) == 0xfec0
}

/// 64:ff9b:1::/48（RFC 6052 NAT64 非 WKP，local-use）
/// 与 WKP 64:ff9b::/96 区分：此段允许本地部署的 NAT64 前缀
fn is_nat64_non_wkp(ip: Ipv6Addr) -> bool {
    ip.segments()[0] == 0x0064
        && ip.segments()[1] == 0xff9b
        && ip.segments()[2] == 0x0001
        // segments[3..] 可以是任意值（/48 前缀后）
}

/// 100::/64（RFC 6666 Discard-Only Address Block）
fn is_discard_only_ipv6(ip: Ipv6Addr) -> bool {
    ip.segments()[0] == 0x0100
        && ip.segments()[1] == 0
        && ip.segments()[2] == 0
        && ip.segments()[3] == 0
        && ip.segments()[4] == 0
        && ip.segments()[5] == 0
        // segments[6..7] 可以是任意值（/64 前缀后）
}

/// 2001:2::/48（RFC 5180 Benchmarking）
fn is_benchmarking_ipv6(ip: Ipv6Addr) -> bool {
    ip.segments()[0] == 0x2001
        && ip.segments()[1] == 0x0002
        // segments[2..] 可以是任意值（/48 前缀后）
}

/// Teredo 隧道 2001:0::/32（RFC 4380）
/// Teredo 地段嵌入客户端 IPv4，易被用于 SSRF 绕过
fn is_teredo(ip: Ipv6Addr) -> bool {
    ip.segments()[0] == 0x2001 && ip.segments()[1] == 0
}

/// 6to4 (2002::/16) 嵌入 IPv4 提取
fn extract_6to4(ip: Ipv6Addr) -> Option<Ipv4Addr> {
    if ip.segments()[0] == 0x2002 {
        let v4_bits = ((ip.segments()[1] as u32) << 16) | (ip.segments()[2] as u32);
        Some(Ipv4Addr::from(v4_bits))
    } else {
        None
    }
}

/// NAT64 WKP (64:ff9b::/96) 嵌入 IPv4 提取
fn extract_nat64(ip: Ipv6Addr) -> Option<Ipv4Addr> {
    if ip.segments()[0] == 0x0064 && ip.segments()[1] == 0xff9b
        && ip.segments()[2] == 0 && ip.segments()[3] == 0
        && ip.segments()[4] == 0 && ip.segments()[5] == 0
    {
        // NAT64 /96 前缀后，IPv4 占 segments[6..8]（高16位+低16位）
        let v4_bits = ((ip.segments()[6] as u32) << 16) | (ip.segments()[7] as u32);
        Some(Ipv4Addr::from(v4_bits))
    } else {
        None
    }
}
```

### §5.2 C-W1/C-W4 S3 HostResolver trait + fail-closed + resolve_and_check（单次 resolve 流水线）

**目标**：DNS 解析失败从 `unwrap_or(false)` 改为显式 `Err`；抽取 trait 以便单测 mock；交付 `resolve_and_check` 作为唯一流水线入口。

**安全设计修正（Oracle 审查后）**：
- **删除 `Resolved::Unpinned`**：原设计 trust + DNS fail → Unpinned → 系统 DNS 返回私网 → 直连，实质绕过 S2 IP 黑名单
- **新语义**：trust 时 DNS fail → 重试一次 → 仍失败则 **reject**（不再有 Unpinned 可连接状态）
- **理由**：避免 Unpinned 时序绕过 S2 IP 黑名单（Oracle 标记为高风险）

**实现**：
```rust
/// DNS 解析抽象，默认走系统 to_socket_addrs
pub(crate) trait HostResolver: Send + Sync {
    fn resolve(&self, host: &str, port: u16) -> Result<Vec<SocketAddr>, String>;
}

pub(crate) struct SystemResolver;

impl HostResolver for SystemResolver {
    fn resolve(&self, host: &str, port: u16) -> Result<Vec<SocketAddr>, String> {
        (host, port)
            .to_socket_addrs()
            .map(|iter| iter.collect())
            .map_err(|e| format!("DNS 解析失败: {e}"))
    }
}

/// 测试用 MockResolver（§4 C-W4 可 mock 要求）
/// 构造规格：`MockResolver { responses: Vec<Result<Vec<SocketAddr>, String>> }`
/// - `responses`：按调用顺序返回的结果序列（第一次 resolve 取 responses[0]，第二次取 [1]，...）
/// - `call_count`：记录 resolve 被调用次数（用于断言 rebinding pin 只 resolve 一次）
/// - **耗尽语义（P0-1 写死，全文唯一）**：空队列 **或** `index >= responses.len()` → **返回 `Err`**，**禁止** `idx.min(len-1)` 复用末条。
///   上层 `resolve_and_check` / `resolve_and_pin` 对 resolve Err **fail-closed**（trust 仅允许再 resolve 一次，仍 Err 则对外 sanitize Err）。
///
/// 各 it 构造→操作→期望示例：
/// - `dns_fail_is_closed`：`MockResolver { responses: vec![Err("mock DNS fail".into())], .. }`
///   → `resolve_and_check("example.com", 443, &mock, false)` 返回 `Err`
/// - `rebinding_pins_first_resolve`：`MockResolver { responses: vec![Ok(vec![public_ip])], .. }`（仅 1 条）
///   → `resolve_and_pin` 后 `call_count == 1`，pin 列表仅含 public_ip；若再 `resolve` 一次 → `Err`（耗尽，不复用 public_ip）
/// - `dns_fail_with_trust_retries`：`MockResolver { responses: vec![Err("fail1".into()), Err("fail2".into())], .. }`
///   → `resolve_and_check(..., true)` 返回 `Err`（重试仍失败），`call_count == 2`
/// - `dns_fail_with_trust_retry_succeeds`（Commit 2 必加，DoD #24）：
///   `MockResolver { responses: vec![Err("fail1".into()), Ok(vec![public_socket])], .. }`
///   → `resolve_and_check(..., true)` 返回 `Ok`（addrs 含 public），`call_count == 2`
/// - `mock_resolver_exhausted_returns_err`（Commit 2 必加）：`responses: vec![Ok(vec![public])]`，连续 resolve 两次 → 第二次 `Err("MockResolver: 响应队列已耗尽")`
#[cfg(test)]
pub(crate) struct MockResolver {
    pub responses: Vec<Result<Vec<SocketAddr>, String>>,
    pub call_count: std::sync::atomic::AtomicUsize,
}

#[cfg(test)]
impl HostResolver for MockResolver {
    fn resolve(&self, _host: &str, _port: u16) -> Result<Vec<SocketAddr>, String> {
        let idx = self.call_count.fetch_add(1, std::sync::atomic::Ordering::SeqCst);
        // P0-1：禁止 min 复用末条；越界 / 空队列 = resolve error
        match self.responses.get(idx) {
            Some(r) => r.clone(),
            None => Err("MockResolver: 响应队列已耗尽".into()),
        }
    }
}

/// 单次 resolve + 校验：resolve 一次，校验同一批 addrs，返回 Vec<SocketAddr>
/// trust_host=true 时 DNS fail → 重试一次 → 仍失败则 Err
/// trust_host=false 时 DNS fail → Err
/// 任何情况 DNS Ok 但含禁用 IP → Err
/// ⚠️ IP 字面量跳过 DNS（P0-3）：直接 SocketAddr + S2 校验
pub(crate) fn resolve_and_check(
    host: &str,
    port: u16,
    resolver: &dyn HostResolver,
    trust_host: bool,
) -> Result<Vec<SocketAddr>, String> {
    // ⚠️ IP 字面量跳过 DNS（P0-3）
    // 去掉方括号后尝试 parse 为 IpAddr
    let bare = host.strip_prefix('[').and_then(|s| s.strip_suffix(']')).unwrap_or(host);
    if let Ok(ip) = bare.parse::<std::net::IpAddr>() {
        let addr = SocketAddr::new(ip, port);
        if is_disallowed_webdav_ip(ip) {
            tracing::warn!("IP 字面量 {} 命中 S2 黑名单", ip);
            return Err(sanitize_webdav_error("IP 字面量命中 S2 黑名单"));
        }
        return Ok(vec![addr]);
    }

    let addrs = match resolver.resolve(host, port) {
        Ok(addrs) => addrs,
        Err(e) if trust_host => {
            tracing::warn!("trust_host=true: DNS 解析失败 ({host}): {e}，重试一次");
            // trust 时重试一次，仍失败则 reject
            resolver.resolve(host, port).map_err(|e2| {
                tracing::warn!("trust_host=true: DNS 重试仍失败 ({host}): {e2}");
                // ⚠️ 脱敏：DNS 错误细节仅进 tracing，对外不暴露（§5 通用约束）
                sanitize_webdav_error("DNS 解析失败（重试后仍失败）")
            })?
        }
        Err(e) => {
            tracing::warn!("DNS 解析失败 ({host}): {e}");
            return Err(sanitize_webdav_error("DNS 解析失败"));
        }
    };

    if addrs.is_empty() {
        return Err(sanitize_webdav_error("DNS 解析失败：未返回任何地址"));
    }

    // 校验所有 IP（S2 黑名单）
    for addr in &addrs {
        if is_disallowed_webdav_ip(addr.ip()) {
            // ⚠️ 脱敏：具体 IP 仅进 tracing，对外 Err 不暴露（§5 通用约束）
            tracing::warn!("主机 {} 解析到禁止的 IP {}", host, addr.ip());
            return Err(sanitize_webdav_error("主机校验失败：不能指向本机或内网"));
        }
    }

    Ok(addrs)
}
```

**关键设计决策**：
1. **IP 字面量跳过 DNS（P0-3，写死）**：`resolve_and_check` 入口处，若 `host` 可直接 parse 为 `Ipv4Addr` 或 `Ipv6Addr`（去掉方括号后），则跳过 `resolver.resolve`，直接构造 `SocketAddr::new(ip, port)` + 运行 S2 `is_disallowed_webdav_ip` 校验。**理由**：IP 字面量无需 DNS 解析；带括号 IPv6（如 `[::1]`）走 `to_socket_addrs` 可能失败；公网 IPv6 字面量走 DNS 可能被 fail-closed 误杀。
2. **单次 resolve**：`resolve_and_check` 只调用一次 `resolver.resolve`，返回 `Result<Vec<SocketAddr>, String>`
3. **trust + DNS fail → 重试一次**：重试仍失败则 **reject**（不再有 Unpinned 可连接状态）
4. **trust + DNS Ok + 私网 IP → 仍 reject**：S2 黑名单不跳过（C-W2/C-W6）
5. **禁止二次 resolve**：`build_webdav_http_client` 直接用 `resolve_and_check`，不再调用旧 `host_resolves_to_disallowed_webdav_ip`

**写死（v1.28 仲裁）— http localhost 连接例外**：
- `normalize_webdav_url` **继续**保留现网 `is_http_localhost_exception`：仅允许 `http://localhost` / `http://127.0.0.1` / `http://[::1]`（及既有等价）作为 scheme 例外。
- **连接路径**（`resolve_and_check` → pin → 实际请求）：对 **https 一律 S2**（含 loopback）fail-closed，**无** trust 旁路。
- `resolve_and_check` 仅收 host/port，**自身保持严格 S2**；**caller**（`build_webdav_http_client` 等）在调用前若 URL 满足与 `is_http_localhost_exception` **同一谓词**（http + localhost/loopback 字面量 host），可 short-circuit 跳过 `resolve_and_check` 的 loopback 拒绝并继续连接；**禁止**扩到 https、域名、非 loopback。
- 必测：normalize 接受 `http://localhost`；`https://localhost` 连接/redirect 仍拒；`http://localhost` 连接允许（与现网一致）。

**废弃**：原 `host_resolves_to_disallowed_webdav_ip` 函数在 Commit 2 合入后删除，所有调用点改用 `resolve_and_check`。

**normalize 路径改造规格（C-W1 关键约束）**：

`normalize_webdav_url`（L292）当前调用 `reject_internal_https_host`，后者对域名路径会触发 DNS 查询。**必须改造**（非确认）：域名路径禁止 DNS，仅格式+字面量 IP 早拒绝。

**实现方案（采用源码级门禁 only）**：

| `last_user_agent` | `Option<String>` | `Some(WEBDAV_USER_AGENT)` 可选 |
测试注入：包装 `ClientBuilder` 或在 `resolve_and_pin` 返回后对 builder 侧车 recorder；**禁止**无 recorder 仅 assert call_count 就宣称 S1 关闭。

```rust
/// 解析 + 校验 + 准备 pin 列表（纯函数，可单测）
/// 返回 (canonical_host, addrs_to_pin, builder_with_user_agent_timeout)
/// ⚠️ 入口强制 canonicalize（P0-4）：防止调用方漏传非 canonical host 导致 pin key 失配
fn resolve_and_pin(
    host: &str,
    port: u16,
    resolver: &dyn HostResolver,
    trust_host: bool,
) -> Result<(String, Vec<SocketAddr>, reqwest::ClientBuilder), String> {
    // ⚠️ 入口强制 canonicalize：所有下游（resolve_to_addrs key、请求 URL、redirect original_host）
    // 必须使用同一 canonical 字符串，防止 pin key 与请求 host 不一致导致 rebinding 防护丢失
    let canonical_host = canonical_host_from_str(host);
    let addrs = resolve_and_check(&canonical_host, port, resolver, trust_host)?;
    let builder = reqwest::Client::builder()
        // P1-19 / P1-15：UA 与超时 SSOT
        .user_agent(WEBDAV_USER_AGENT)  // 常量 = 现网字面量 "SoNotes/1.5"（~L437）；本版不改字符串
        .timeout(Duration::from_secs(WEBDAV_HTTP_TIMEOUT_SECS)); // 命名常量；默认 30；可测点 = 该 const
    Ok((canonical_host, addrs, builder))
}

fn build_webdav_http_client(
    host: &str,
    port: u16,
    timeout: Duration,
    resolver: Arc<dyn HostResolver>,
    trust_host: bool,
) -> Result<reqwest::Client, String> {
    // 1. 单次 resolve + 校验 + pin 列表（可测），canonical_host 从 resolve_and_pin 内部产出
    let (canonical_host, addrs, mut builder) = resolve_and_pin(host, port, resolver.as_ref(), trust_host)?;
    builder = builder.timeout(timeout);

    // 2. Pin 到解析后的 IP（一次性 pin 全部已校验地址，禁止循环覆盖）
    // ⚠️ reqwest 的 resolve(host, addr) 同 host 多次调用会覆盖，不是累加
    // 必须用 resolve_to_addrs 一次 pin 全部，否则只保留最后一个 IP
    // ⚠️ P0-1 修复：pin key 必须用 canonical_host，与 redirect 闭包捕获的 original_host 同源
    builder = builder.resolve_to_addrs(&canonical_host, &addrs);

    // 3. Redirect policy — 捕获注入的 resolver + canonical host:port（同 host:port only 策略）
    let resolver_for_redirect = Arc::clone(&resolver);
    // ⚠️ P0-1 修复：捕获 canonical_host 而非原始 host，确保 pin key == redirect 比较基准
    let original_host = canonical_host.clone();
    let original_port = port;
    builder = builder.redirect(reqwest::redirect::Policy::custom(move |attempt| {
        if attempt.previous().len() >= MAX_WEBDAV_REDIRECTS {
            attempt.error("WebDAV redirect limit exceeded")
        } else if validate_webdav_redirect_url(
            attempt.url(),
            &original_host,
            original_port,
            resolver_for_redirect.as_ref(),
        ).is_err() {
            attempt.error("WebDAV redirect target rejected")
        } else {
            attempt.follow()
        }
    }));

    builder.build().map_err(|e| {
        tracing::warn!("HTTP client 构建失败: {e}");
        sanitize_webdav_error("HTTP client 构建失败")
    })
}
```

**关键设计决策**：
1. **调用 resolve_and_check**：直接用 §5.2 的流水线，不再重复实现
2. **trust + DNS fail → 重试一次**：重试仍失败则 reject（不再有 Unpinned 可连接状态）
3. **redirect 闭包捕获注入的 resolver**：通过 `Arc::clone` 传入，测试可注入 MockResolver
4. **redirect 不 pin**：`validate_webdav_redirect_url` 只校验不 pin（见 §5.4）
5. **可测性**：`resolve_and_pin` 返回 `(canonical_host, addrs, builder)`，测试直接断言 canonical_host 和 pin 列表，不依赖 Client 内部 API
6. **⚠️ resolve_to_addrs 一次 pin**：禁止循环 `builder.resolve(host, addr)`（同 host 多次调用会覆盖，只留最后一个 IP）；必须用 `builder.resolve_to_addrs(host, &addrs)` 一次 pin 全部已校验地址

**host 规范化同源约束 + pin/URL 同源接线规则（P0-3，可执行，写死）**：

> `ClientBuilder::resolve_to_addrs(host, &addrs)` / pin 按**字符串 key** 覆盖 DNS。若 pin 使用的 `host` 与实际请求 URL 的 `host` 字节级不一致（如 `Example.com` vs `example.com`、`example.com.` vs `example.com`），pin **静默失效**，回退系统 DNS，S1 rebinding 防护丢失。

### §5.4 Redirect 永不 trust + 同 host only（C-W3）

**当前签名**：`validate_webdav_redirect_url(url: &Url) -> Result<(), String>`（L412）

**改造**：
1. 增加 `original_host` 参数，只允许同 host redirect（防止跨 host 凭据泄露）
2. 增加 `original_port` 参数，同 host 必须同 port（防止不同端口绕过）
3. 增加 `resolver` 参数，调用时**固定** `trust_host=false`

```rust
fn validate_webdav_redirect_url(
    url: &Url,
    original_host: &str,  // 新增：原始 host，只允许同 host redirect
    original_port: u16,   // 新增：原始 port，只允许同 port redirect
    resolver: &dyn HostResolver,
) -> Result<(), String> {
    if url.scheme() != "https" {
        return Err(sanitize_webdav_error("重定向目标必须使用 HTTPS"));
    }
    let host = url.host().ok_or_else(|| sanitize_webdav_error("重定向目标缺少主机名"))?;

    // ⚠️ trailing-dot 一律拒绝（Oracle HIGH-1 修复）
    // reqwest resolve_to_addrs 的 pin key 是字节级 host 字符串
    // Location host="example.com." 会导致 pin key 失配，静默回退系统 DNS
    if let url::Host::Domain(d) = host {
        if d.to_ascii_lowercase().ends_with('.') {
            return Err(sanitize_webdav_error("重定向目标 host 含末尾点（trailing-dot），已拒绝"));
        }
    }

    // 同 host+port 策略：防止跨 host/跨 port 凭据泄露（Oracle 审查建议）
    // ⚠️ P0-2 修复：reqwest 用 Location URL 原文 host 作为 pin key 查找
    // 若 Location host 与 pin key 字节级不一致（如 Example.COM vs example.com），
    // pin 静默失效，回退系统 DNS，S1 rebinding 防护丢失
    // 因此必须用字节级全等比较，不做任何规范化
    let redirect_host_raw = url.host_str().ok_or_else(|| sanitize_webdav_error("重定向目标缺少主机名"))?;
    if redirect_host_raw != original_host {
        return Err(sanitize_webdav_error("重定向目标 host 与 pin key 不一致（字节级全等要求）"));
    }

    // port 比较：使用 port_or_known_default() 规范化（https 默认 443）
    let redirect_port = url.port_or_known_default().unwrap_or(443);
    if redirect_port != original_port {
        return Err(sanitize_webdav_error("重定向目标 port 不匹配"));
    }

    // 重定向永不 trust（C-W3）
    reject_internal_https_host(url, &host, resolver, false)
}
```

**关键设计决策**：
1. **同 host+port only**：redirect 只允许同一 host:port，防止跨 host/跨 port 凭据泄露（Oracle 标记为中风险）
2. **永不 trust**：redirect 目标走完整 S1/S2/S3 校验，忽略 trust 配置
3. **trailing-dot 一律拒绝**：Location host 含 trailing-dot 直接 reject，防止 pin key 失配导致 TOCTOU 重开（Oracle HIGH-1 修复）
4. **port 比较规范化**：使用 `port_or_known_default()`，https 默认 443，防止 `host:443` 与 `host` 不匹配
5. **⚠️ redirect 与 pin key 字节级全等（P0-2，写死）**：`validate_webdav_redirect_url` 比较 Location host 原始字符串与 `original_host`（pin key）**字节级全等**，不做任何规范化。reqwest 用 Location URL 原文 host 作为 pin key 查找；若字节不一致（如 `Example.com` vs `example.com`），pin 静默失效，回退系统 DNS，TOCTOU 重新打开。**强制规则**：redirect 闭包捕获的 `original_host` 必须是 `canonical_host_from_str(host)` 的结果，与 pin key 完全一致；Location host 必须与 `original_host` 字节级全等才允许 follow。

`reject_internal_https_host` 签名同步改为 `(&Url, &Host<&str>, &dyn HostResolver, bool)`。

**辅助函数**：
```rust
/// 规范化 host 用于比较：统一处理 Domain/IPv4/IPv6
/// Domain：ASCII 小写 + 去掉末尾点（trailing dot）
/// IPv4：直接 to_string()
/// IPv6：固定格式 `[ip]`（带方括号）
fn canonical_host(host: url::Host<&str>) -> String {
    match host {
        url::Host::Domain(d) => {
            let lower = d.to_ascii_lowercase();
            lower.trim_end_matches('.').to_string()
        }
        url::Host::Ipv4(ip) => ip.to_string(),
        url::Host::Ipv6(ip) => format!("[{ip}]"),
    }
}

/// 从字符串规范化 host（用于 original_host 参数）
fn canonical_host_from_str(host: &str) -> String {
    // ⚠️ 带方括号的 IPv6（如 "[::1]"）：必须先 trim 方括号再 parse，
    // 否则 parse::<Ipv6Addr> 失败会落入 Domain 分支，得到错误的 "[::1]" 小写字符串路径
    let trimmed = host.trim();
    let bare = trimmed
        .strip_prefix('[')
        .and_then(|s| s.strip_suffix(']'))
        .unwrap_or(trimmed);

    // 尝试解析为 IP，否则当作 Domain
    if let Ok(ip) = bare.parse::<std::net::Ipv4Addr>() {
        return ip.to_string();
    }
    if let Ok(ip) = bare.parse::<std::net::Ipv6Addr>() {
        return format!("[{ip}]");
    }
    // Domain：ASCII 小写 + 去掉末尾点
    // ⚠️ 必须基于 trimmed（已 trim 空格），否则前后空格导致 pin key 与 redirect 比较不一致
    let lower = trimmed.to_ascii_lowercase();
    lower.trim_end_matches('.').to_string()
}
```

**IPv6 方括号处理（写死）**：

> `canonical_host_from_str("[::1]")` 等带方括号的 IPv6 **必须**先 `strip_prefix('[')` + `strip_suffix(']')` 再 `parse::<Ipv6Addr>`，避免落入 Domain 分支。输出固定为 `[ip]` 格式，与 `canonical_host(Host::Ipv6(_))` 一致。

**注意**：
- `build_webdav_http_client` 的 redirect 闭包需要捕获原始 host 和 port，传入 `validate_webdav_redirect_url`

**序列化兼容（P0-8 写死）**：
- Rust：所有新增 `trust_host: bool` **必须** `#[serde(default)]`（default = false）；`trusted_host` `#[serde(default)]` → None。
- 旧配置 JSON **无** `trust_host`/`trusted_host` → 加载为 `false` / `None`，**不得**反序列化失败。
- TS：`trustHost?: boolean`（optional）或读取时 `?? false`；**禁止**把 `trustHost` 做成无 default 的必填导致旧前端/部分 payload 炸；与 C-W5「最小语义」一致（缺省 = 不信任）。
- 验收 it：`trust_host_defaults_false_on_old_config`（Commit 4）：旧 JSON 无 trust 字段 → load 后 `trust_host==false`。

**trust 与 host 绑定逻辑（对齐 Decision 4；P1-trust host change opt-in）**：
- **方案 A（采用）**：`load_config` / `prepare_config_save` 唯一负责绑定校验，连接时只信 `trust_host: bool`
- `prepare_config_save` 时（**增量**改现网，禁止重写毁掉 credentials）：
  - host **未变**（canonical 相同）：`trust_host = request.trust_host`；若 true 则 `trusted_host = Some(new_host)`
  - host **已变** 且 `request.trust_host == false`（未 re-opt-in）：**清空** → `trust_host=false`，`trusted_host=None`（测名 `trust_cleared_when_host_changes`）
  - host **已变** 且 `request.trust_host == true`（用户显式勾选）：**绑定新 host** → `trust_host=true`，`trusted_host=Some(new_host)`（测名 `trust_set_on_host_change_when_user_opts_in`）
- `load_config` 时：若 `trusted_host` 存在且不匹配当前 `server_url`，则返回 `trust_host=false`
- **连接时不校验 trusted_host**：`build_webdav_http_client` 只读 `WebDavConfig.trust_host`

**trusted_host 指纹规范化（强制）**：
- 存储时：`trusted_host = Some(canonical_host_from_str(host))`（使用 §5.4 的 `canonical_host_from_str` 函数）
- 比较时：`canonical_host_from_str(new_host) == trusted_host`
- 规范化规则：Domain ASCII 小写 + 去掉末尾点；IPv4 直接 to_string；IPv6 固定 `[ip]` 格式
- **禁止裸字符串比较**：防止 `Example.com` / `example.com.` / `EXAMPLE.COM` 绕过

```rust
/// 增量改造：保留现网 remember_password / credential_key / old_credential_key；
/// 仅插入 trust_host / trusted_host 绑定逻辑。
fn prepare_config_save(
    request: &WebDavConfigSaveRequest,
    old_config: Option<&WebDavConfigFile>,
) -> Result<(WebDavConfigFile, Option<String>), String> {
    let server_url = normalize_webdav_url(&request.server_url)?;
    let remote_dir = normalize_remote_dir(request.remote_dir.as_deref().unwrap_or(""))?;

    let new_key = compute_credential_key(&server_url, &request.username, &remote_dir);
    let old_credential_key = old_config.and_then(|c| c.credential_key.clone());

    // ── trust 绑定（P1-trust opt-in）：仅 ADD，不改 credential 语义 ──
    // P1-16：host 数据源 = **已 normalize 的 server_url**（上一步 normalize_webdav_url(&request.server_url)）
    // 解析其 host_str → canonical；**不是** raw request.server_url 未规范化副本，也不是 draft 其它字段
    let host_str = Url::parse(&server_url)
        .ok()
        .and_then(|u| u.host_str().map(|s| s.to_string()))
        .unwrap_or_default();
    let new_host = canonical_host_from_str(&host_str);
    let old_trusted = old_config.and_then(|c| c.trusted_host.clone());

    let (trust_host, trusted_host) = match old_trusted {
        Some(ref fp) if *fp == new_host => {
            // host 未变：按 request 写入；true 时刷新指纹
            if request.trust_host {
                (true, Some(new_host.clone()))
            } else {
                (false, None)
            }
        }
        Some(_) if request.trust_host => {
            // host 已变 + 用户显式 opt-in → 绑定新 host
            // 测：trust_set_on_host_change_when_user_opts_in
            (true, Some(new_host.clone()))
        }
        Some(_) => {
            // host 已变 + 未 re-opt-in → 清空
            // 测：trust_cleared_when_host_changes
            tracing::info!("[WebDAV] host 变更且未重新勾选信任，trust_host 已重置为 false");
            (false, None)
        }
        None => {
            // 首次 / 旧配置无指纹
            if request.trust_host {
                (true, Some(new_host.clone()))
            } else {
                (false, None)
            }
        }
    };

    // ── 现网 credential 路径原样保留 ──
    if request.remember_password {
        if request.password.as_deref().unwrap_or("").is_empty() {
            return Err("勾选记住密码时必须提供密码".to_string());
        }
        let config = WebDavConfigFile {
            server_url,
            username: request.username.clone(),
            remote_dir,
            password_saved: true,
            credential_key: Some(new_key), // 禁止写成 None
            trust_host,
            trusted_host,
        };
        return Ok((config, old_credential_key));
    }

    let config = WebDavConfigFile {
        server_url,
        username: request.username.clone(),
        remote_dir,
        password_saved: false,
        credential_key: None, // 仅「不记住密码」分支
        trust_host,
        trusted_host,
    };
    Ok((config, old_credential_key))
}
```

## §9 风险与对策

### 风险简表

| 风险 | 等级 | 对策 |
|------|------|------|
| pin key 不一致（normalize 一份、请求/redirect 用另一份） | 高 | `canonical_host`/`canonical_port` 唯一来源 + trailing-dot 策略 + `pin_host_*` / `redirect_rejects_trailing_dot_host` 测 |
| Unpinned 回潮（trust + DNS fail 直连） | 高 | 已删除 `Resolved::Unpinned`；trust 仅重试一次，仍失败则 reject |
| 跨 host redirect 兼容性 | 中 | CHANGELOG 披露「仅同 host redirect」+ §10 真机确认主流 WebDAV |
| webdav.rs 改造冲突（签名连锁、调用方漏改） | 中 | §5.3 调用方清单 + 编译绿 + `redirect_guard_*` / 操作入口回归测 |
| trust UX 误解（以为可连内网 NAS） | 低-中 | 文案强调「IP 黑名单仍生效」；错误文案脱敏，不暴露解析 IP |

> **错误信息脱敏（与 §5 通用约束一致）**：对外错误统一笼统表述（如「不能指向本机或内网」）；解析 IP / DNS 细节只进 `tracing`，不暴露给前端。

### §9.1 设计决策记录

> Oracle 审查后沉淀的关键决策，避免后续含糊。每条决策含理由、后果、与 Oracle 建议对齐说明。

#### Decision 1: trust 语义 = DNS 重试（非 fail-open）

**决策**：`trust_host=true` 时 DNS fail → 重试一次 → 仍失败则 **reject**（不再有 Unpinned 可连接状态）。

**理由**：
- Oracle 审查发现：原 Unpinned 设计实质绕过 S2 IP 黑名单（高风险）
- 重试一次覆盖「DNS 临时抖动」场景，但不接受「持续失败就裸奔」
- 对齐 C-W2/C-W6 约束

**后果**：
- 用户自家 NAS 若 DNS 持续不可用，即使勾选 trust 仍会被拒绝
- UI 文案已更新：「信任此主机（DNS 失败时重试；IP 黑名单仍生效）」

**与 Oracle 建议对齐**：
Oracle 建议的「DNS 重试后仍失败则 reject」方案已实现，消除 Unpinned 时序绕过 S2 IP 黑名单的高风险。

#### Decision 2: redirect 策略 = 同 host only + 永不 trust

**决策**：redirect 目标必须与原始 host 一致（同 host only），走完整 S1/S2/S3 校验，**永不 trust**。

**理由**：
- Oracle 审查发现：跨 host redirect 可能泄露凭据（中风险）
- reqwest 架构限制：`ClientBuilder::resolve` 在 build 时固定，无法对运行时新 host 动态 pin
- 同 host only 大幅砍 TOCTOU 面

**后果**：
- WebDAV 跨域 302 redirect 将被拒绝（需用户确认这是可接受的）
- 校验→连接之间仍存在 DNS rebinding TOCTOU（仅同 host）

**缓解**：
- redirect 永不 trust（C-W3）
- 同 host only 策略已实现（防止跨 host 凭据泄露）
- 同 host 时，`ClientBuilder::resolve` pin 的 IP 对后续 redirect 仍生效（reqwest 连接复用 pin 的 SocketAddr），实际连接不会经过二次 DNS 解析

**与 Oracle 建议对齐**：
Oracle 建议的同 host only 策略已实现，大幅降低 TOCTOU 攻击面（防止跨 host 凭据泄露）。

**TOCTOU 风险说明（Oracle MEDIUM-2 修正）**：
redirect 场景下，**仅当** follow 使用的 host 字符串与 pin key **完全一致**时，TOCTOU 可忽略。reqwest 连接池复用已 pin 的 SocketAddr，实际连接不会经过二次 DNS 解析。
1. redirect 永不 trust（C-W3）
2. 同 host only 策略（防止跨 host 凭据泄露）
3. **前提条件**：follow 的 host ≡ pin key（字节级一致）；若 Location host 含 trailing-dot，已一律 reject（Oracle HIGH-1 修复）
4. **已知限制**：若 redirect 跨 host（本版已禁止），reqwest 架构限制无法对新 host 动态 pin
5. **注意**：证书校验只验主机名，不钉 IP——证书不能防 DNS rebinding SSRF，pin 才是防 rebinding 的核心机制

#### Decision 3: 删除 Unpinned 可连接状态

**决策**：删除 `Resolved::Unpinned` enum variant，`resolve_and_check` 直接返回 `Result<Vec<SocketAddr>, String>`。

**理由**：
- Oracle 审查发现：Unpinned 时序绕过 S2 IP 黑名单（高风险）
- trust + DNS fail → 系统 DNS 返回私网 → 直连，实质绕过 S2 黑名单
- 新语义：trust 时重试一次 DNS，仍失败则 reject

**后果**：
- 无 fail-open 路径，所有连接都经过 S2 IP 黑名单校验
- trust 仅影响 DNS 重试行为，不影响 IP 黑名单

**与 Oracle 建议对齐**：
Oracle 建议的删除 Unpinned 可连接状态已实现，消除时序绕过 S2 IP 黑名单的高风险。

**缓解**：
- UI 文案已更新为「信任此主机（DNS 失败时重试；IP 黑名单仍生效）」
- 单测：`dns_fail_with_trust_retries`（重试仍失败）+ `dns_fail_with_trust_retry_succeeds`（重试成功）+ `dns_fail_with_trust_still_rejects_private`

#### Decision 4: trust 与 host 绑定（防止语义越权；P1-trust opt-in）

**决策**：
- host **未变**：按 `request.trust_host` 写入
- host **已变** 且 **未** re-opt-in（`request.trust_host=false`）→ **清空** trust
- host **已变** 且 **用户 opt-in**（`request.trust_host=true`）→ **绑定新 host**（`trust_host=true`，`trusted_host=Some(new)`）

**理由**：
- 裸 bool 在改 URL 后仍 true → 语义越权
- 但若用户改 host 时**同时勾选**信任，应绑定新 host，而非一律清空（P1-trust）
- 对齐 C-W2

**实现**：见 §5.5 增量 `prepare_config_save`（保留 credential 路径）

**测试**：
- `trust_cleared_when_host_changes`：host 变更无 re-opt-in → false
- `trust_set_on_host_change_when_user_opts_in`：host 变更 + trust=true → 绑定新 host
- `trust_persists_when_host_same`：host 不变 → 保持

**后果**：
- 改地址且未重新勾选 → trust 重置
- 改地址且勾选 → 信任新 host

#### Decision 5: S1 收窄 = pin + 主机名证书（无 TLS/SAN 二次构造）

**决策**：S1 关闭状态字 = **已收窄**，不是「已修复（含 TLS/SAN 二次校验）」：
1. **必做**：连接时 `resolve_and_check` → `resolve_to_addrs` / `ClientBuilder::resolve` **pin** 首次通过 S2 的地址
2. **依赖**：reqwest 默认 **hostname** 证书校验（只验配置主机名）
3. **不做**：握手后独立构造 SAN/证书与目标 IP 的二次校验；证书钉 IP

**理由**：
- 证书只验主机名，**不能**单独防 DNS rebinding；**pin 才是 rebinding 闭合核心**
- 独立 SAN 二次构造成本高、与 reqwest 默认栈重复，YAGNI
- 与 Decision 2 第 5 点一致（证书不钉 IP）

**后果**：
- 审查报告 / 总规划 §4.0 必须写 **S1 已收窄**，禁止宣称「S1 已完全按旧总规划 TLS 二次校验修复」
- 残余同 host TOCTOU 面见 §10 / Decision 2

**与总规划对齐**：总规划 §4.1 S1 行与 §4.7 TLS 对策已回写为 pin + reqwest hostname verification。
